# 김아근의 수업자료일람

수업 자료와 학급 운영 링크를 주제별 폴더와 즐겨찾기로 정리한 사이트입니다.

- 사이트: GitHub Pages로 공개합니다(Settings → Pages, `main` / `(root)`).
- 저장소: 구글 시트 + Apps Script. `apps-script-Code.gs`를 시트의 확장 프로그램 → Apps Script에 붙여 넣고 웹 앱으로 배포한 뒤, 그 주소를 `config.js`에 넣습니다.
- 관리자 비밀번호는 코드에 없습니다. 시트 메뉴 [수업자료일람 > 관리자 비밀번호 설정]에서 정합니다.
