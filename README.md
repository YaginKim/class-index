# 김아근의 수업자료일람

수업 자료와 학급 운영 링크를 주제별 폴더와 즐겨찾기로 정리한 사이트입니다.

- 사이트: GitHub Pages로 공개합니다(Settings → Pages, `main` / `(root)`).
- 저장소: 구글 시트 + Apps Script. `apps-script-Code.gs`를 시트의 확장 프로그램 → Apps Script에 붙여 넣고 웹 앱으로 배포한 뒤, 그 주소를 `config.js`에 넣습니다.
- 관리자 비밀번호는 코드에 없습니다. 시트 메뉴 [수업자료일람 > 관리자 비밀번호 설정]에서 정합니다.

## 관리자만 보기 폴더

- 관리자로 로그인한 뒤 폴더 카드의 자물쇠 버튼(또는 폴더 편집 창의 "관리자만 보기" 스위치)을 켜면, 그 폴더는 로그인하지 않은 사람에게 보이지 않습니다.
- 화면에서만 숨기는 것이 아니라, Apps Script가 누구나 읽는 목록에서 그 폴더를 빼고 보내고 비밀번호가 맞을 때만 전체 목록을 보냅니다.
- 이 기능을 쓰려면 `apps-script-Code.gs`의 새 코드를 시트의 Apps Script에 붙여 넣고 [배포 > 배포 관리 > 수정 > 버전: 새 버전 > 배포]로 다시 배포해야 합니다. 웹 앱 주소는 그대로입니다.
